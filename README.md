# WhatFirst

## サービス概要
やることの優先順位を整理し、  
「次にやるべきタスク」をひと目で把握できるWebアプリ

## 想定されるユーザー層
- やることは多いが、何から手を付けるべきか迷ってしまう人
- タスクの優先度付けが苦手な人
- 自分用に、できるだけシンプルなToDoアプリを使いたい人

## サービスコンセプト
このアプリは、  
「何をやるか」ではなく「何からやるか」を決めることに  
フォーカスしたシンプルなToDoアプリです。  
  
タスク管理機能を最小限に絞り、  
優先度と完了状態だけを扱うことで、  
迷わず次の行動に移れることを目的としています。

## 実装を予定している機能
### MVP
* タスクの新規作成・編集・削除
* 優先度（高・中・低）の設定
* 未完了 / 完了の切り替え
* 優先度順での表示

### MVPに含めなかった機能
* 期限
* 通知
* ユーザー管理
* カテゴリ分け

### MVPに含めなかった理由
機能が増えるほど、判断コストが増えるため。# WhatFirst
